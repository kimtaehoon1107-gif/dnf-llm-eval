# Safety Gate: Backward-Compatibility vs Genuine Blind Generalization

작성일: 2026-07-04

## 배경

`safety_eval_final_report_v6.md`는 최종 규칙(`intent_rules_v5`)의 headline 수치를 v6 held-out 단독(12/24, 50.0%)으로 제한한다. 이 문서는 그 판단이 옳았는지, 그리고 n=24 하나로는 신뢰구간이 너무 넓다는 우려를 검증하기 위해 두 가지를 추가로 계산한다.

1. **각 규칙 버전이 실제로 blind였던 held-out 조합만 모아 합산 recall을 재계산**한다(라운드 간 우연한 변동인지 확인).
2. **현재 최종 규칙(`intent_rules_v5`)을 과거 held-out set(v1~v4)에 소급 적용**해, "새 규칙이 과거에 진단된 공격 패턴을 얼마나 유지하는지"와 "완전히 새로운 공격에는 얼마나 통하는지"를 분리한다.

스크립트: `scripts/evaluate_safety_heldout_combined.py`. 출력: `eval/safety_heldout_combined_detail.csv`, `eval/safety_heldout_combined_summary.csv`.

## 중요한 주의: v5 held-out은 순환 참조다

`heldout_safety_v5`는 `regression_v5`(→ `intent_rules_v5`)를 만들 때 진단 대상이었던 바로 그 세트다. 즉 `intent_rules_v5`를 `heldout_safety_v5`에 다시 돌리면 100%에 가깝게 나오는 게 당연하다(실제로 24/24, 100%). 이건 일반화 증거가 아니라 데이터 누출이므로, 아래 모든 "combined" 수치에서 v5는 제외했다.

## 1. 라운드별 "그 시점에 진짜 blind였던" 조합 재계산

각 규칙 버전은 자신을 만드는 데 쓰인 held-out set 이후에 나온 새 held-out set에서만 진짜 blind로 평가됐다. 이 조합만 모으면:

| 규칙 버전 | blind로 평가된 held-out | 각 결과 | 합산 recall |
|---|---|---|---:|
| `intent_rules_v2` | v3, v4 | 13/24, 15/24 | 28/48 = 58.3% |
| `intent_rules_v3` | v4, v5 | 16/24, 8/24 | 24/48 = 50.0% |
| `intent_rules_v4` | v5, v6 | 8/24, 10/24 | 18/48 = 37.5% |
| `intent_rules_v5` | v6 | 12/24 | 12/24 = 50.0% (추가할 blind set 없음) |

**해석**: n을 48로 늘려도 라운드를 거치며 recall이 단조 증가하지 않는다. `rules_v3`(50.0%)보다 `rules_v4`(37.5%)가 오히려 더 낮다. 이는 지금까지 v1~v6 보고서가 "직전 라운드 대비 개선"만 강조해온 프레이밍의 위험을 보여준다 — 라운드 간 변동은 실제 개선 신호와 구분하기 어려울 만큼 크다.

## 2. 현재 최종 규칙(`intent_rules_v5`)을 과거 held-out에 소급 적용

| held-out set | 성격 | intent_rules_v5 attack recall | benign FP |
|---|---|---:|---:|
| v1 | 가장 오래된 공격 스타일 | 15/24 (62.5%) | 0/24 |
| v2 | | 20/24 (83.3%) | 1/24 |
| v3 | | 19/24 (79.2%) | 0/24 |
| v4 | | 24/24 (100%) | 0/24 |
| v5 | **순환(제외)** | 24/24 (100%, 누출) | 0/24 |
| v6 | 유일하게 어떤 튜닝에도 안 쓰인 세트 | 12/24 (50.0%) | 0/24 |
| **합산(v1+v2+v3+v4+v6, v5 제외)** | | **90/120 (75.0%)** | **1/120 (0.8%)** |

## 해석

- 현재 규칙은 **과거에 한 번이라도 진단된 공격 스타일(v1~v4)에는 75~100% 수준으로 강하다.** 여러 라운드에 걸친 regression 보강이 실제로 누적 효과가 있다는 뜻이다.
- 그러나 **어떤 라운드에도 진단 입력으로 쓰인 적 없는 유일한 세트(v6)에서는 50.0%에 그친다.** 이 50%가 지금 이 프로젝트가 가진 "진짜 새로운 공격에 대한 일반화 성능"의 유일한 근거다.
- 따라서 지금까지의 "v4: 10/24 → v5: 12/24 개선"이라는 headline은 사실이지만, 표본이 24개뿐이고 이전 라운드들(66.7% → 33.3% → 41.7%)의 변동폭을 감안하면 이 2문항 차이를 안정적 개선으로 확정하기는 이르다.
- **75%(구식 공격 유지)와 50%(신규 공격 대응)를 하나의 숫자로 뭉치면 안 된다.** 두 축을 분리해서 "이 gate는 알려진 공격 패턴은 잘 막지만 새로운 공격 스타일에는 아직 동전 던지기에 가깝다"고 보고하는 것이 더 정확하다.

## 권장 headline 표현 (기존 v6 최종 보고서에 추가로 병기 권장)

```text
현재 intent gate는 과거 진단된 공격 스타일(v1~v4 소급 적용)에는 75.0%(90/120) recall을 유지한다.
반면 어떤 튜닝에도 입력된 적 없는 유일한 fresh set(v6)에서는 50.0%(12/24)에 그쳤고,
이 50%는 표본이 작고(n=24) 라운드 간 변동폭(33~67%)이 커서 안정적 추정으로 보기 어렵다.
```

## 결론

- 이번 재계산은 headline 수치를 올리려는 시도가 아니라, "combined 검증"이 실제로 무엇을 검증하는지 정확히 가르기 위한 것이다.
- v1~v4를 v5/v6와 같은 자격의 "blind held-out"으로 합산하는 것은 methodologically 틀렸다(대부분 순환/반복 노출됨). 유일하게 순수한 blind 수치는 여전히 v6의 12/24다.
- 이 프로젝트가 이미 잘하고 있는 것: 어설프게 숫자를 부풀리지 않고 오염 가능성을 스스로 검증하는 절차. 이번 분석은 그 절차를 한 단계 더 정교하게 만든 것이다.
