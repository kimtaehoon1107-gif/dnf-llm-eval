# 수집 문서 요약

작성일: 2026-05-27

## 개요

현재 수집된 던전앤파이터 업데이트 문서 5개를 LLM 평가 데이터셋 후보로 검토했다. 문서들은 정기점검 업데이트, 퍼스트 서버 업데이트, 주요 업데이트로 구성되어 있으며, 게임 시스템/보상/콘텐츠 입장 조건/신규 캐릭터 등 실제 유저 질문으로 전환하기 좋은 정보를 포함한다.

## 문서별 요약

### DOC-01: 5/28(목) 정기점검 업데이트 안내

- 문서 유형: regular_update
- 게시일: 2026.05.28
- 핵심 내용: 아포칼립스 : 안티엔바이 1, 2단계 클리어 보상과 NPC 켈돈 자비 상점 판매 품목 변경
- 주요 정보:
  - 광휘의 잔영은 NPC 켈돈 자비 상점 구매 재화로 사용된다.
  - 태초 광휘의 의지는 광휘의 잔영 790개로 계정당 1회 구매 가능하다.
  - 태초 소울 1개 상자는 광휘의 잔영 120개로 계정당 월 4회 구매 가능하다.
  - 에픽 소울 1개 상자는 광휘의 잔영 8개로 계정당 월 15회 구매 가능하다.
  - 영롱한 조율의 추 1개 상자는 광휘의 잔영 360개로 계정당 월 4회 구매 가능하다.
- 평가 질문화 포인트: 보상 변경, 상점 구매 조건, 구매 제한, 재화 용도

### DOC-02: 5/20(수) 퍼스트 서버 업데이트 안내

- 문서 유형: first_server
- 게시일: 2026.05.20
- 핵심 내용: 신규 캐릭터 제국기사와 첫 번째 전직 브레이커 추가
- 주요 정보:
  - 퍼스트 서버는 5월 20일 오후 3시에 오픈된다.
  - 신규 캐릭터 제국기사가 추가된다.
  - 브레이커는 제국기사의 첫 번째 전직이다.
  - 브레이커는 방어구 장착 시 주요 능력치와 물리 방어력, HP/MP 관련 보너스를 받는다.
  - 브레이커의 주요 스킬로 덱 브레이커, 와이드 클리브, 캐넌 킥, 러프 보딩, 훅 샷 등이 있다.
- 평가 질문화 포인트: 신규 캐릭터, 전직 관계, 스킬 설명, 퍼스트 서버와 라이브 서버 차이

### DOC-03: 5/21(목) 정기점검 업데이트 안내

- 문서 유형: regular_update
- 게시일: 2026.05.20
- 핵심 내용: 광휘의 행로 시스템 추가
- 주요 정보:
  - 광휘의 행로는 NPC 붉은 성화의 엘리아 메뉴를 통해 진행한다.
  - 명성 58,950 이상의 캐릭터로 탐사를 진행할 수 있다.
  - 탐사는 계정 단위이며 한 번에 하나만 진행할 수 있다.
  - 접속 여부와 관계없이 탐사 시간이 흐른다.
  - 매주 1회 핀더의 정원 탐사를 무료로 진행할 수 있다.
  - 순례의 인장 1개를 추가 소모하면 잔여 탐사 시간을 2분 단축할 수 있다.
  - 기억의 숲 탐사는 4시간, 단초의 길 탐사는 12시간, 핀더의 정원 탐사는 20시간이 걸린다.
- 평가 질문화 포인트: 시스템 이용 조건, 탐사별 소모 재료, 시간 단축 규칙, 계정 단위 제한

### DOC-04: 최후의 과업 업데이트

- 문서 유형: main_update
- 게시일: 2026.05.13
- 핵심 내용: 최후의 과업 라이브 서버 조정 및 콘텐츠 배경 설명
- 주요 정보:
  - 퍼스트 서버 피드백을 바탕으로 라이브 서버 업데이트 시 몬스터 HP가 10% 일괄 하향된다.
  - 성화 작열 HP 감소량은 40%에서 30%로 조정된다.
  - 신야, 밀란 로젠바흐의 핵심 패턴 발동 시작 시점이 개선된다.
  - 제휴 아바타 일정은 검토 필요 사항으로 인해 향후로 조정된다.
  - 퍼스트 서버 HP를 100으로 보면 라이브 서버 HP는 90, 성화 작열 감소 HP는 30으로 설명된다.
- 평가 질문화 포인트: 퍼스트 서버 피드백 반영, 수치 변경, 디렉터 코멘트 해석, 콘텐츠 조정 의도

## 데이터 품질 점검 결과

- Markdown 한글 본문은 UTF-8 기준 정상이다.
- PowerShell `Get-Content` 출력에서는 깨져 보일 수 있으나 파일 자체 문제는 아니다.
- 최신 글이 목록에서 날짜 대신 시간만 표시되는 문제는 제목의 월/일을 이용해 보정했다.
- 현재 5개 문서는 질문 생성용 1차 데이터로 사용 가능하다.
